Portfolio

Qué hago

Este mismo servidor es una muestra en vivo: infraestructura propia, hardenizada y desplegada de punta a punta.

Seguridad & hardening

TLS, headers de seguridad (HSTS, X-Frame-Options), ocultamiento de versión de servidor, principio de menor privilegio en firewall y accesos.

CI/CD & deploys

Despliegues con Docker y Coolify, integración con GitHub, entornos reproducibles de código a producción.

Automatización con IA

Workflows con n8n, agentes conectados a modelos locales (Ollama) y RAG con base de conocimiento propia.

Arquitectura Full Stack

APIs REST con NestJS, frontends con Next.js/Angular/React, bases de datos SQL y NoSQL, todo conectado end-to-end.
